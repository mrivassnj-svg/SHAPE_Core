 it validates and fixes it in a closed loop."

# ──────────────────────────────────────────────────────────
# CLIP 05 — Code Overview  [3:30 – 4:10]
# ──────────────────────────────────────────────────────────
[CUE 00:03:30 – 00:04:10]  CLIP_CODE
Visual: VS Code or file tree shown. Each file highlighted as mentioned.
        Quick scroll through agent.py showing the ReAct prompt.
        Quick show of feedback.py rolling average calculation.

Voice:
"The codebase has five core modules.
 agent.py wires together LangChain, Ollama, and four tools
 inside a ReAct executor with a sliding-window conversation memory —
 keeping RAM usage low on the Pi.
 safety.py screens every request with regex patterns before it reaches the model —
 blocking harmful commands, destructive shell calls, and out-of-scope requests.
 feedback.py is our reinforcement learning component.
 After each response, the user rates it one to five stars.
 A rolling average of those scores generates a policy hint
 that's prepended to the next prompt — nudging the agent to do better.
 The four tools — code executor, linter, file manager, and doc search —
 each handle one kind of action the agent can take."
